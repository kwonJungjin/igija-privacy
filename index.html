이기자 개인정보처리방침

시행일: 2026년 8월 3일 · 앱: 이기자 · 운영 주체: 이기자

이기자는 사용자가 정한 앱 사용 계약을 기기에서 관찰하고 집행하는 Android 앱입니다.

회원가입과 로그인 기능은 없으며, 개발자 서버·광고·분석 SDK를 사용하지 않습니다.

문의: weneedsomeigija@outlook.com

1. 처리하는 정보

앱 사용정보

사용정보 접근을 허용하면 감시 중이거나 대시보드를 보는 동안 Android가 제공하는 최근 10분의 앱 전환 기록을 확인합니다. 여기에는 계약 대상뿐 아니라 최근 화면에 올라온 다른 앱의 패키지명과 전환 시각도 포함될 수 있습니다. 감시 중에는 앱 전환 또는 차단 상태가 바뀐 시점의 패키지명, 시각, 차단 상태를 기기 안의 장부에 저장합니다.

설치 앱 정보

사용자가 ‘앱 목록 불러오기’를 누르면 런처에서 실행할 수 있는 설치 앱의 이름, 패키지명, 아이콘을 읽습니다. 전체 목록과 아이콘은 선택 화면에만 사용하고 목록 자체를 저장하지 않습니다. 사용자가 선택한 앱의 패키지명은 계약과 규칙 이력에 저장합니다.

계약과 사용 상태

담보 그룹의 이름과 내부 ID, 선택한 앱의 패키지명, 하루 예산, 굿나잇 시간, 사용 시간, 과업으로 받은 시간, 멀티플 단계와 날짜 상태를 저장합니다.

과업과 시작 사진

사용자가 입력한 과업 이름과 수행 시간, 시작 사진, 시작·완료·포기·세션 유실 시각, 지급 시간과 자주 쓰는 과업을 저장합니다. 완료된 시작 사진은 오늘의 인증을 표시하는 데 사용합니다. 카메라 취소·명시 포기·세션 생성 실패 때 새 내부 사진을 정리하지만, 촬영 성공 뒤 앱 프로세스가 예기치 않게 끝나면 미완료 사진이 앱 데이터에 남을 수 있습니다.

앱 운영 장부

감시 ON·OFF와 복구 결과, 사용정보 접근의 해제·복구, 차단 표시·해제 시각, 규칙 변경, 재부팅 횟수, 시계 변경 감지, 일별 판정과 스트릭을 저장합니다. 이 정보는 계약 집행, 상태 복원, 장부와 리캡 표시에 사용합니다.

온보딩 진행 상태

첫 계약을 마치기 전에는 현재 단계와 편집 중인 그룹 이름, 예산, 선택 앱을 저장해 앱을 다시 열었을 때 이어서 진행합니다. 민감정보 공개문 확인 버전도 기기에 저장합니다.

2. 이용 목적

처리한 정보는 사용자가 정한 앱 사용 계약 집행, 대상 앱 사용 시간 계산과 차단 화면 표시, 담보 앱 선택, 과업 수행과 시간 지급 기록, 장부·오늘의 인증·리캡·스트릭 표시, 명시적으로 켠 감시의 정상 재부팅 뒤 복구, 권한·알림·저장 실패 상태 고지에만 사용합니다.

3. 저장 위치와 외부 전송

계약·현재 상태·온보딩 상태는 Android SharedPreferences에, 역사 장부와 일별 판정은 Room 데이터베이스에 저장합니다. 새로 촬영한 과업 사진은 내부 앱 전용 저장소에 저장합니다. 이전 버전에서 촬영한 사진은 기존 외부 앱 전용 폴더에 남아 있을 수 있습니다.

이기자 앱에는 인터넷 권한과 개발자 서버 전송 코드가 없습니다. 앱이 이 정보를 개발자, 광고업체 또는 분석업체로 보내거나 판매하지 않습니다.

사진 촬영에는 사용자가 선택한 카메라 앱을 사용하며, 사진 촬영을 위해 한 장의 저장 위치를 카메라 앱에 전달합니다. 카메라 앱 자체의 처리는 해당 앱의 정책을 따릅니다.

4. Android 백업과 기기 이전

Android 백업 또는 기기 이전이 켜져 있으면 운영체제가 계약, 장부, 설정과 사진 일부를 사용자의 Google 계정 백업 영역이나 새 기기로 옮길 수 있습니다. 이는 이기자 개발자 서버로 보내는 전송이 아닙니다.

다른 기기에서 감시가 저절로 켜지지 않도록 감시 ON 복구 의도는 백업과 기기 이전에서 제외합니다. 민감정보 공개문 확인 기록도 제외하므로 복원된 기기에서는 공개문을 다시 확인하고 감시를 다시 켜야 합니다.

5. 보관과 삭제

별도 자동 삭제 기한은 두지 않습니다. 완료된 과업 사진과 장부는 사용자가 Android 설정에서 이기자의 앱 데이터를 삭제하거나 앱을 삭제할 때까지 기기에 남습니다.

그룹이나 과업 프리셋을 삭제해도 이미 기록된 장부와 완료된 인증 사진은 함께 삭제되지 않습니다.

기기 안의 전체 데이터를 지우려면 Android 설정의 이기자 앱 정보에서 저장공간의 앱 데이터 삭제를 실행하거나 앱을 삭제할 수 있습니다. Android 백업 사본은 기기 또는 Google 계정의 백업 설정에서 별도로 관리해야 하며, 개발자는 기기나 Google 계정의 백업을 원격으로 열거나 삭제할 수 없습니다.

6. 권한과 사용자 선택

사용정보 접근을 끄면 앱 전환을 볼 수 없어 사용 시간 계산과 차단 판단을 수행하지 못합니다. 다른 앱 위 표시를 끄면 차단 화면을 보여 줄 수 없습니다. 상시 알림을 표시할 수 없으면 감시를 시작하지 않거나 실행 중인 감시를 멈춥니다.

감시를 명시적으로 끄면 정상 재부팅 뒤에도 꺼진 상태로 둡니다. 정상 재부팅 뒤 자동 복구는 완료된 계약, 확인한 민감정보 공개문, 명시적으로 켠 감시, 표시 가능한 상시 알림이 모두 있을 때만 시도합니다. Android 설정의 강제 종료는 우회하지 않습니다.

화면이 꺼진 뒤에도 감시를 계속하려면 앱 정보의 배터리 설정에서 ‘제한 없음’을 선택해야 합니다. 권한을 허용하지 않거나 감시를 끄더라도 계약 편집과 앱 삭제를 방해하지 않습니다.

7. 보호 조치와 한계

새로 만드는 데이터는 Android 앱 전용 내부 저장 영역과 앱 샌드박스 안에 둡니다. 이기자는 별도의 앱 자체 파일 암호화를 추가하지 않습니다.

이전 버전의 외부 앱 전용 사진 폴더는 Android 9 이하에서 저장소 권한을 가진 다른 앱이 접근할 가능성이 있습니다. 새 사진은 내부 앱 전용 저장소를 사용합니다.

Google Play로 설치한 경우 Google은 자체 정책에 따라 충돌·ANR 같은 진단 정보를 처리하고 Play Console에 제공할 수 있습니다. 이기자에는 별도 Crashlytics·Sentry 등의 수집 SDK가 없습니다.

8. 방침 변경과 문의

처리 항목이나 기능이 바뀌면 이 방침과 앱 안의 공개문을 함께 갱신합니다. 새 확인이 필요하면 공개문 버전을 올려 다시 확인을 받습니다.
